## Getting Started
Clone the repository
In terminal, cd to the 'poc' folder

### Create virtual environment
python3 -m venv venv
source venv/bin/activate

### Install dependencies
pip install -r requirements.txt

### Run the application
python app.py


### To access the SQLite database
In a separate terminal window, cd to the 'instance' folder in the 'poc' folder

Run the command: sqlite_web travelgo.db
